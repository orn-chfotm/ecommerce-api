# 현재 구현상 주의점

## 문서 범위

현재 코드 기준으로 확인된 미구현 기능, 애매한 구현, 문서화 시 주의할 점을 정리한다.

## 주의점

- README와 일부 Swagger 설명/예외 메시지 문자열은 인코딩이 깨져 있어 문구 근거로 사용하지 않았다.
- 결제 기능은 없다.
- 배송 상태 변경 API는 없다.
- 주문 취소는 사용자 API만 있고 관리자 주문 관리 API는 없다.
- 상품 수정 API는 없다.
- 옵션 등록 후 옵션 수정/삭제 API는 없다.
- 장바구니에서 주문 생성 후 장바구니를 비우는 로직은 없다.
- 찜 중복 방지 로직은 없다.
- 상품 삭제는 soft delete지만 목록/상세 조회에서 삭제 상품 제외 여부는 repository 구현 확인이 필요하다.
- 옵션 템플릿은 독립 CRUD이며 상품 옵션 등록에 자동 적용되지 않는다.

## 문서 갱신 기준

- API 추가/변경 시 컨트롤러 endpoint와 권한을 갱신한다.
- 서비스 비즈니스 규칙 변경 시 해당 도메인 규칙을 갱신한다.
- DTO validation 변경 시 입력 제약을 갱신한다.
- 엔티티 상태값이나 enum 변경 시 상태/카테고리 표기를 갱신한다.
- 구현되지 않은 기능을 예정 기능처럼 쓰지 않는다.
